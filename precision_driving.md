# Precision driving challenge

The objective of the Precision Driving Challenge was to combine vehicle navigation measurement, real-time data processing and accurate driving.
The Mini Cooper had to pass through a set of predefined virtual gates while maintaining a specified velocity at each gate. The vehicle position was evaluated using the Polygon plugin for DewesoftX.
Polygon allows GNSS/INS navigation data to be represented in a local coordinate system and enables geometrical objects such as vehicles, tracks and virtual gates to be defined.
